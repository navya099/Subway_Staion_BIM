# 마감 텍스처 이미지

이미지는 저장소에 포함합니다. 출처: 사용자가 직접 준비·제작(일부 이미지 생성 AI 로 생성) — 재배포에 문제 없는 파일만 둡니다.
콘크리트(`Polished Concrete New`)는 재배포 가능한 이미지로 교체해 둡니다 (스케치업 기본 재질 이미지는 넣지 않음).
같은 규칙으로 `../light/`(조명 켜짐·꺼짐), `../mep/`(설비 디퓨저) 텍스처를 둡니다 (아직 코드에서 쓰지 않음).

출력 탭의 **텍스처 DAE**(스케치업 둘러보기용 COLLADA)가 쓰는 이미지입니다. 2D 도면·IFC 에는 쓰지 않습니다.

| 파일 이름 (.jpg / .jpeg / .png) | 마감 재질 이름 | 이미지 한 장의 실제 크기 (가로 × 세로) |
|---|---|---|
| `metal_panel` | 금속패널 (벽·기둥 둘레) | 1.2 m × 0.6 m |
| `granite` | 화강석 (바닥) | 0.6 m × 0.6 m |
| `stair_stone` | 계단석 (계단 디딤판·계단참·챌판·통석, 바닥 화강석과 구분되는 무늬 — 이음매 없는 정사각 타일 권장) — **디딤판 윗면은 한 장씩 맞춤**: 가로 = 계단 폭 방향(마감 탭 '계단석 한 장 길이'로 폭을 고르게 나눔), 세로 = 단너비, 이미지 아래쪽 = 앞 코. 계단참·챌판 등은 일반 타일 | 0.6 m × 0.6 m (타일일 때) |
| `ceiling_panel` | 알루미늄 천장판 (천장) | 0.6 m × 0.6 m |
| `tactile_warning` | 점자블록 점형 (경고) | 0.3 m × 0.3 m |
| `tactile_guide` | 점자블록 선형 (유도) — 줄 방향은 이미지 가로 = 선형 진행방향 | 0.3 m × 0.3 m |
| `tactile_boarding` | 승하차위치표시 (연단 띠 중 열차 문 앞, 분홍) | 0.3 m × 0.3 m |
| `Polished Concrete New` | 콘크리트 (구조 부재 기본: 벽·슬래브·승강장·기둥·계단·통로·출입구·환기구·승강로) + 콘크리트 면처리 | 2.0 m × 2.0 m |

- 마감 탭의 재질 이름이 위 이름과 **정확히 같은** 마감에만 텍스처가 붙습니다. 다른 재질은 색만 씁니다.
- 구조 부재(콘크리트)는 마감과 관계없이 항상 콘크리트 텍스처를 씁니다 (에스컬레이터·칸막이벽·문·그릴·엘리베이터 카는 색만).
- 이미지는 이음매 없이 반복되는(seamless) 한 장이면 됩니다. 패널 줄눈을 이미지 가장자리에 넣으면 실제 패널 크기대로 줄눈이 보입니다.
- 벽은 가로 = 수평, 세로 = 위쪽. 바닥·천장은 가로 = 선형 진행방향, 세로 = 진행방향 왼쪽.
- 크기·파일 이름은 `exporter/render_material.py` 의 `FINISH_MATERIALS` 에서 바꿉니다.
- 이미지가 없으면 출력은 되고, 완료 알림에 "텍스처 이미지 없음 → 색만" 으로 표시됩니다.
- 출력하면 이미지가 `.dae` 옆 `textures/` 폴더로 복사됩니다 (스케치업에서 가져올 때 함께 있어야 함).

- 역명판·안내사인 이미지는 여기 두지 않습니다. 출력할 때 사인 탭 입력으로 그려서 `textures/sign_###.png` 로 저장합니다.
