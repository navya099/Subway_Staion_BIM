조작

왼쪽 끌기 = 회전, 오른쪽(또는 Shift) 끌기 = 이동, 휠 = 확대
클릭 = 부재 정보, 더블클릭 = 그 점을 회전 중심으로
걷기: WASD 이동, 마우스 = 시선, Shift 달리기, Space 점프, PgUp/PgDn 층 이동, C 충돌 켬·끔(끄면 벽 통과, E/Q 위·아래), Esc 끝
문: 걷기에서 F 또는 클릭(2.5m 안), 전체 보기에서는 클릭 = 여닫기, 자동문은 다가가면 열림
엘리베이터: 호출 버튼 클릭(걷기는 가운데 점), 카 안에서는 1~9 = 층 선택(아래부터)
